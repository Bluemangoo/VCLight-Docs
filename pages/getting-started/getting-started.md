# Getting Started

## Before starting

- Install a recent [Node.js](https://nodejs.org/) version (18+ recommended)
- Create a [Vercel](https://vercel.com/) account if you plan to deploy on Vercel

## Quick start with VCLight CLI (recommended)

Create a project:

::: code-group
```shell [npm]
npx @vclight/cli create my-vclight-app
```

```shell [pnpm]
pnpx @vclight/cli create my-vclight-app
```
:::

Or install the CLI globally first:

::: code-group
```shell [npm]
npm install -g @vclight/cli
vclight create my-vclight-app
```

```shell [pnpm]
pnpm add -g @vclight/cli
vclight create my-vclight-app
```
:::

The CLI will ask you to pick:

- preset: router template or blank template
- handlers: Vercel / Netlify / Node HTTP
- optional features: Prettier / `.gitignore`

## Manual setup

Create a project and install dependencies:

::: code-group
```shell [npm]
npm init -y
npm install vclight
npm install -D @types/node typescript
```

```shell [pnpm]
pnpm init
pnpm add vclight
pnpm add -D @types/node typescript
```
:::

If you use router middleware, also install:

::: code-group
```shell [npm]
npm install @vclight/router
```

```shell [pnpm]
pnpm add @vclight/router
```
:::

## Entry file examples

### Vercel (Node runtime)

```typescript
import app from "./app/app";

export default app.vercelHandler();
```

### Node HTTP server

```typescript
import * as http from "http";
import app from "./app/app";

const server = http.createServer();
server.on("request", app.httpHandler());
server.listen(3000);
```

### Netlify Functions

```typescript
import app from "../../src/app/app";

export default app.netlifyHandler();
```

## Local debugging

Use the script generated by your selected handler(s):

- `dev:vercel` for Vercel
- `dev:netlify` for Netlify
- `dev:http` for Node HTTP

Example:

```shell
npm run dev:vercel
```
